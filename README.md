# ゲームリスト

個人用のゲームリスト。PCで編集し、GitHub Pagesの閲覧画面で確認します。

## 使い方

1. `ゲームリストを開く.cmd` をダブルクリックします。
2. 一覧の興味・ROM所有・探し中を変更します。PCへ自動保存されます。
3. タイトルを押すとメモ、以前のExcelの記号、対応機種の根拠を確認できます。
4. `スマホ用を更新` で暗号化した閲覧用データをGitHubへ送ります。
5. `閲覧画面` から自分専用のURLをコピーし、スマホでブックマークします。

## 発売情報の確認（2026年9月7日）

登録済み3,567本を発売一覧と照合し、公式資料で確認した発売日11件・タイトル20件を訂正、未登録のGBA作品2本を追加しました。
興味・所有・探し中・メモ・元の記録は保持しています。訂正前の情報と出典は作品の詳細に表示します。
その後、日付相違65件と表記の違いで同定保留だったDH2を個別調査し、発売日をさらに24件訂正しました。35件は調査資料に基づき登録日を採用、資料が食い違った6件はユーザー指定によりExcel記載日を採用しました。SYSTEM Ver2.0は別バージョンの日付が混在していたため、他のシステムカード類5件とともにゲームの通番から除外しました。
公式資料・報道・書籍・販売店等の複数資料を区別して表示します。日付の不一致が解消できない場合はExcel記載日を優先します。Excelにない作品は資料掲載日、年しか分からない作品は整理用に1月1日を設定し、詳細に明示します。調査記録はデータに保持しています。元Excelと同系統の一覧しかない作品もあり、全作品を一次資料で確認したものではありません。
再販候補21件のうち20件を通常版へ統合、テクモ スーパーボウル2は続編として維持しました。追加確認した名作シリーズ2件・バーディガンの別パッケージ1件も統合し、計23件を整理しました。統合前の各版の記録は詳細で確認・検索できます。
PCエンジンはビックリマン大事界、ULTRABOX全6号、国内非公認23作品の計30本を追加しました。mama Mitteと恐竜図鑑はゲーム対象外です。
全161項目の処理が完了しています。残っていた9作品にも上記の採用方針を反映済みです。J・サンダーは1994年1月1日として登録し、発売順にも含めます。システムカード6件を除いた3,570本を通番の集計対象としましたが、その後のユーザー指定により画面のNo表示は廃止しました。
端末内の `発売情報の確認結果.html` に相違点と出典をまとめています。公開するのは暗号化した記録だけです。

`release_date_evidence.json` に66件の採用日・理由・出典を記録し、`catalog_followup.py` で反映しています。追加・統合の対応表と出典は `catalog_completion_evidence.py`、反映処理は `catalog_finalize.py` です。ユーザー指定の日付の採用方針は `catalog_date_policy.py` で反映しています。

`audit_catalog.py` はこの調査時の外部一時キャッシュを読む照合処理、`catalog_review.py` は確認済み訂正の適用処理です。
キャッシュはGitに含めていません。再調査では資料の再取得・内容確認が必要です。適用済みの同じ訂正は再実行できません。

## 保存と公開

`library.json` に編集内容を保存し、直前の保存を `library.previous.json` に残します。
個人の記録、解除用の鍵、専用URL、ローカル設定はGit対象外です。
GitHub PagesにはAES-256-GCMで暗号化した記録と閲覧画面を置きます。
解除用の256ビット鍵は端末上で生成し、専用URLの `#` 以降に含めます。
このURLを知っている人は記録を読めます。GitHubや他人には送らず、ご自身だけで保管してください。
データファイルを直接公開したり、鍵をHTMLへ埋め込んだりしません。
暗号処理はPythonのcryptographyとブラウザのWeb Crypto APIを使います。
https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt
https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment

ローカルサーバーは127.0.0.1にのみ待ち受け、編集はローカルの同一オリジンからだけ受け付けます。
スマホでの表示にはPCの起動は不要です。編集内容は更新ボタンを押すまで反映されません。
スマホ用データは全記録をgzipで圧縮してから暗号化します。PCの一覧データも圧縮して転送し、ファイルが変わるまでサーバー側で再利用します。保存内容を省略せず、再読み込み時の転送・処理を減らしています。

ファミ通の1990〜2022年の発売記録を基礎に、任天堂公式、セガ公式、国内の発売一覧（super-famicom.jp、GDR、GAVAS）で補完しました。ゲームギアはセガ公式196本、N64は国内一覧を基礎に任天堂公式の日付を照合しています。今回の取り込みに出所不明の海外サイトは使っていません。

本体・周辺機器、海外版と明記された商品、体験版・追加コンテンツは除外しています。PS系の旧機種互換ダウンロードは元機種の作品として扱い、受け側の機種に重ねて登録しません。DSi専用・New 3DS専用・64DD・3DSのバーチャルコンソールは別区分です。同じ作品の通常版・廉価版・限定パッケージをまとめ、ポケモンの別バージョン等、内容が異なる版は分けています。

採用した一覧の収録範囲に基づく追加です。全作品をメーカーの一次資料で確認した網羅保証ではありません。資料に発売元やジャンルがない作品は「未確認」「未分類」と表示します。以前の「発売情報の確認結果」はExcel由来3,576件の調査記録であり、今回の追加15,485件の個別調査報告ではありません。

個人記録を含まない追加用カタログは `追加ハードの発売一覧.json`、取り込み処理は `import_hardware_catalog.py` です。`--apply` は未登録IDだけを追加し、繰り返しても既存の編集内容を上書きしません。通常の取り込みはオフラインです。各作品の資料URLと統合した版のタイトル・発売日を詳細に残しています。
機種追加はユーザーの指定ごとに行います。別機種版とリメイクは分け、廉価版・限定パッケージはまとめます。
探し中は興味・ROM所有から独立し、機種を横断して確認できます。

## 起動環境

このPCにあるCodex付属Pythonを使います。npmや追加パッケージのインストールは不要です。
起動用ランタイムが削除された場合は起動設定の修正が必要です。
